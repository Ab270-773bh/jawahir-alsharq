# جواهر الشرق — متجر إلكتروني

مشروع React + Vite + Supabase، مناسب للهواتف ويضم:
- واجهة عربية RTL متجاوبة ورسوم حركة خفيفة.
- صفحات تفاصيل المنتج، معرض صور متعددة، وصف وطريقة استخدام.
- سلة مشتريات وحفظها محلياً في المتصفح.
- تسجيل حساب الزبون وتسجيل الدخول واستعادة كلمة المرور عبر Supabase Auth.
- حفظ الطلبات وعناصرها ومتابعة حالتها.
- لوحة إدارة محمية لإدارة المنتجات والأسعار والصور والطلبات وروابط التواصل.
- روابط WhatsApp وInstagram وTelegram اختيارية.

## 1) المتطلبات
- Node.js حديث (يفضل 20 أو أحدث) لتشغيل المشروع محلياً.
- حساب Supabase مجاني كبداية.
- بيئة لتشغيل تطبيق React، أو استيراد ملفات المشروع في أداة بناء تدعم React.

## 2) إعداد Supabase
1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor وشغّل كامل الملف `supabase/schema.sql`.
3. من Project Settings > API انسخ Project URL و`anon` / publishable key.
4. انسخ `.env.example` إلى ملف باسم `.env` في جذر المشروع، وضع القيم:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. لا تضع `service_role` key في الواجهة أو داخل `.env` الخاص بالواجهة.
6. من Authentication > URL Configuration عيّن Site URL إلى رابط الموقع المنشور، وأضف رابط المعاودة إلى Redirect URLs.
7. من Authentication > Providers > Email اضبط تأكيد البريد حسب حاجتك. لاستعادة كلمة المرور، يجب أن يعمل البريد الإلكتروني وأن تكون عناوين المعاودة صحيحة.

## 3) إنشاء أول مدير — خطوة أمان ضرورية
1. افتح الموقع وأنشئ حساباً بالبريد الإلكتروني الذي تريد استخدامه كمدير.
2. أكمل تأكيد البريد إذا كان مفعلاً.
3. افتح Supabase > SQL Editor ونفّذ هذا الاستعلام بعد استبدال البريد:
   ```sql
   update public.profiles
   set is_admin = true
   where email = 'YOUR_ADMIN_EMAIL';
   ```
4. سجّل الخروج ثم الدخول من جديد. افتح «لوحة الإدارة».
5. لا تضف زر تسجيل مدير عام، ولا تضع كلمة مرور ثابتة في الكود.

## 4) تشغيل المشروع
```bash
npm install
cp .env.example .env
# املأ بيانات Supabase داخل .env
npm run dev
```
لبناء نسخة للنشر:
```bash
npm run build
npm run preview
```
يمكن نشر مجلد `dist` على خدمة استضافة ثابتة مثل Vercel أو Netlify بعد ضبط متغيرات البيئة.

## 5) الصور والتواصل
- من لوحة الإدارة يمكن رفع صور متعددة إلى Storage bucket اسمه `product-images`.
- يمكن أيضاً إدخال رابط صورة في كل سطر.
- رقم WhatsApp يكتب مع مفتاح الدولة من دون `+` أو مسافات (مثال توضيحي فقط: `9639XXXXXXXX`).
- Instagram وTelegram يقبلان رابط الحساب أو القناة الحقيقي.
- روابط التواصل الموجودة في ملف `.env` هي قيم ابتدائية للواجهة؛ الإعدادات المحفوظة من لوحة الإدارة تُحفظ في جدول `store_settings`. إذا رغبت بتحميلها من قاعدة البيانات تلقائياً عند بدء التشغيل، أضف ذلك إلى `App` قبل النشر (النسخة الأولية تعرض روابط البيئة كقيم افتراضية).

## 6) ملاحظات مهمة قبل البيع الحقيقي
- الأسعار، الشحن، الدفع الإلكتروني، الضرائب، وسياسة الإرجاع تحتاج ضبطاً حسب طريقة عمل المتجر.
- هذه النسخة لا تجمع المدفوعات إلكترونياً؛ الطلب يرسل تفاصيله فقط.
- السلة محفوظة في متصفح الجهاز؛ يجب على الزبون تسجيل الدخول لإرسال طلب محفوظ في حسابه.
- اختبر حساب زبون وحساب مدير في متصفحين مختلفين قبل النشر.
- لا تضع مفاتيح سرية في كود الواجهة.
- المنتجات التجريبية والصور التجريبية أمثلة للعرض. استبدلها بصورك وأوصافك وأسعارك الفعلية.
